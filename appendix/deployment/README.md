# 배포 패턴 (Deployment Patterns)

배포 패턴은 무중단 배포와 안전한 릴리스를 위한 패턴입니다. 다운타임 최소화, 롤백 용이성, 점진적 릴리스를 다룹니다.

## 패턴 목록

| 패턴 | 설명 | 난이도 | 도구 |
|------|------|--------|------|
| [Blue-Green](./BlueGreen) | 두 환경 준비 후 즉시 전환 | ⭐⭐ | K8s Service, LB |
| [Canary](./Canary) | 일부 사용자에게 먼저 배포 | ⭐⭐ | Istio, Spinnaker |
| [Rolling](./Rolling) | 서버 순차 교체 | ⭐ | K8s Rolling Update |
| [Feature Toggle](./FeatureToggle) | 런타임 기능 활성화/비활성화 | ⭐⭐ | LaunchDarkly, Unleash |

## 핵심 개념

### 무중단 배포
서비스 중단 없이 새 버전 배포 및 트래픽 전환

### 롤백
문제 발생 시 이전 버전으로 빠르게 복구

### 배포 vs 릴리스
- **배포**: 코드를 서버에 올리는 행위
- **릴리스**: 사용자에게 기능을 공개하는 행위

## 패턴 선택 가이드

### 빠른 롤백 필요
→ **Blue-Green** (즉시 전환 가능)

### 리스크 최소화
→ **Canary** (점진적 확대)

### 리소스 효율성
→ **Rolling** (최소 리소스)

### 배포/릴리스 분리
→ **Feature Toggle** (코드 배포 후 기능 제어)

## 배포 전략 비교

| 전략 | 롤백 속도 | 리소스 | 리스크 |
|------|----------|--------|--------|
| Blue-Green | 빠름 | 2배 | 낮음 |
| Canary | 빠름 | 추가 | 매우 낮음 |
| Rolling | 느림 | 최소 | 중간 |
