# 직군별 면접 가이드

## 🎯 개요

이 문서는 직군별 채용 면접을 위한 체계적인 질문 가이드입니다.
**Java/Spring 개발자** 가이드를 기본으로 제공하며, **DevOps / SRE** 직군은 별도 폴더에 정리되어 있습니다.
직군 안에서 주니어와 시니어 모두에게 적절한 수준의 질문을 제공하여 효율적인 면접 진행을 돕습니다.

## 💡 면접 팁: STAR 기법

경험 기반 질문에 대한 답변을 이끌어낼 때 **STAR 기법**으로 꼬리 질문을 던지세요.

| 단계 | 질문 예시 |
|------|----------|
| **S** (Situation) | "당시 상황은 어땠나요?" |
| **T** (Task) | "본인의 구체적인 역할과 과제는 무엇이었나요?" |
| **A** (Action) | "어떤 행동/기술적 선택을 했나요?" |
| **R** (Result) | "그 결과 어떤 성과(정량적 수치)나 배움을 얻었나요?" |

### 🔄 추가 꼬리 질문

시니어 개발자 면접에서 특히 유효한 질문:

> "만약 다시 그 상황으로 돌아간다면, 다르게 시도해보고 싶은 것이 있나요?"

이 질문은 **회고 능력**과 **지속적인 학습 태도**를 확인할 수 있습니다.

## ⚖️ 평가 기준

### 주니어 개발자 (0-3년차)

| 평가 항목 | 기대 수준 |
|----------|----------|
| 기본 개념 이해 | Spring, JPA, Java 핵심 개념을 설명할 수 있음 |
| 코드 작성 능력 | 기본적인 CRUD 로직을 구현할 수 있음 |
| 학습 의지 | 새로운 기술에 대한 관심과 학습 경험 |
| 협업 태도 | Git 사용 경험, 코드 리뷰 참여 의지 |

### 시니어 개발자 (4년차 이상)

| 평가 항목 | 기대 수준 |
|----------|----------|
| 심화 기술 이해 | JVM, 동시성, 트랜잭션 등 깊은 이해 |
| 문제 해결 능력 | 복잡한 기술적 문제를 분석하고 해결한 경험 |
| 아키텍처 설계 | 시스템 설계 시 Trade-off를 고려한 의사결정 |
| 리더십 | 주니어 멘토링, 기술 의사결정 주도 경험 |
| 장애 대응 | 운영 환경 장애 대응 및 포스트 모템 경험 |

## 📋 면접 진행 순서 (권장)

### 1단계: 아이스브레이킹 (5분)
- 자기소개
- 최근 관심 있는 기술

### 2단계: 기술 질문 (30-40분)
- **주니어**: 기초 개념 → 실무 적용 경험
- **시니어**: 심화 개념 → 아키텍처 설계 → 장애 대응

### 3단계: 경험/협업 질문 (15-20분)
- 프로젝트 경험 (STAR 기법 활용)
- 협업 및 커뮤니케이션

### 4단계: AI 도구 활용 (10분, 선택)
- AI 도구 사용 경험
- 검증 및 보안 의식

### 5단계: Q&A (5-10분)
- 지원자 질문

## 🎯 효과적인 면접을 위한 팁

### ✅ Do

- 답변 후 **"왜 그렇게 생각하시나요?"** 꼬리 질문
- **구체적인 경험**을 물어보기 (언제, 어디서, 어떻게)
- 틀린 답변에도 **힌트를 주며** 사고 과정 확인
- **편안한 분위기** 조성

### ❌ Don't

- 정답만 요구하는 단답형 질문
- 암기 여부만 확인하는 질문
- 압박 면접으로 긴장감 유발
- 한 질문에 과도한 시간 소요
