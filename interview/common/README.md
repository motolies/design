# 공통 협업·경험 상황 선택

[전체 진행 방법](../README.md) · [평가 주제 대조표](../coverage.md)

상황 1개를 골라 지원자의 답변에 맞는 분기 1~2개만 진행합니다. 기본은 10~15분, 심화는 15~20분이며 경력 연수 대신 관찰한 설명과 검증 근거로 평가합니다. 같은 상황의 기본·심화는 한 문서에서 조건을 달리합니다.

| 상황 제목 | 평가 역량 | 난이도 | 예상 시간 |
|---|---|---|---|
| [일정 안에 모든 요구를 구현할 수 없다](deadline-and-quality.md#basic) | 우선순위 · 비즈니스 이해 · 소통 | 기본 ([심화 경로](deadline-and-quality.md#deep)) | 10~15분 |
| [리뷰 의견 충돌로 배포가 지연된다](review-and-mentoring.md#basic) | 코드 리뷰 · Git · 멘토링 · 의사결정 | 기본 ([심화 경로](review-and-mentoring.md#deep)) | 10~15분 |
| [새 기능과 레거시 개선을 함께 진행해야 한다](legacy-modernization.md#basic) | 리팩토링 · 위험 관리 · 도구 도입 | 기본 ([심화 경로](legacy-modernization.md#deep)) | 10~15분 |
| [직접 구현과 외부 솔루션 중 선택해야 한다](build-or-buy.md#basic) | 설계 선택 · 실험 · 기술 의사결정 | 기본 ([심화 경로](build-or-buy.md#deep)) | 10~15분 |
| [AI가 만든 코드를 이해하지 못한 채 머지하려 한다](ai-generated-change-review.md#basic) | AI 검증 · 보안 · 학습 · 책임 | 기본 ([심화 경로](ai-generated-change-review.md#deep)) | 10~15분 |
| [AI 답변 기능의 품질과 비용을 합의해야 한다](llm-feature-quality.md#basic) | LLM 기능 평가 · 제품 판단 · 실패 대응 | 기본 ([심화 경로](llm-feature-quality.md#deep)) | 10~15분 |

첫 상황에서는 관찰 사실과 가정을 구분하는지, 두 번째에서는 선택의 한계와 실패 시 복구·검증을 설명하는지 확인하세요. 공통 질문도 별도 지식 시험처럼 추가하지 말고 실제 경험으로 이어갑니다.
