# DevOps 협업·운영 상황 선택

[전체 진행 방법](../../README.md) · [평가 주제 대조표](../../coverage.md)

상황 1개를 골라 지원자의 답변에 맞는 분기 1~2개만 진행합니다. 기본은 10~15분, 심화는 15~20분이며 경력 연수 대신 관찰한 설명과 검증 근거로 평가합니다. 같은 상황의 기본·심화는 한 문서에서 조건을 달리합니다.

| 상황 제목 | 평가 역량 | 난이도 | 예상 시간 |
|---|---|---|---|
| [새벽 장애의 담당팀과 운영 권한이 불명확하다](on-call-ownership.md#basic) | 온콜 · 책임 경계 · 사고 소통 | 기본 ([심화 경로](on-call-ownership.md#deep)) | 10~15분 |
| [비용 절감 요구와 배포 위험이 충돌한다](cost-and-change-budget.md#basic) | 비용 · 변경 관리 · 자동화 우선순위 | 기본 ([심화 경로](cost-and-change-budget.md#deep)) | 10~15분 |
| [AI가 만든 코드를 이해하지 못한 채 머지하려 한다](../../common/ai-generated-change-review.md#basic) | AI 검증 · 보안 · 학습 · 책임 | 기본 ([심화 경로](../../common/ai-generated-change-review.md#deep)) | 10~15분 |

첫 상황에서는 관찰 사실과 가정을 구분하는지, 두 번째에서는 선택의 한계와 실패 시 복구·검증을 설명하는지 확인하세요. 공통 질문도 별도 지식 시험처럼 추가하지 말고 실제 경험으로 이어갑니다.
