# 프론트엔드 협업·운영 상황 선택

[전체 진행 방법](../../README.md) · [평가 주제 대조표](../../coverage.md)

상황 1개를 골라 지원자의 답변에 맞는 분기 1~2개만 진행합니다. 기본은 10~15분, 심화는 15~20분이며 경력 연수 대신 관찰한 설명과 검증 근거로 평가합니다. 같은 상황의 기본·심화는 한 문서에서 조건을 달리합니다.

| 상황 제목 | 평가 역량 | 난이도 | 예상 시간 |
|---|---|---|---|
| [배포 후 로그인과 주문 화면 통신이 실패한다](../advanced/login-and-contract-failure.md#basic) | 인증 · 브라우저 보안 · BFF · 계약 검증 | 기본 ([심화 경로](../advanced/login-and-contract-failure.md#deep)) | 10~15분 |
| [새 버전 배포 뒤 일부 사용자에게 흰 화면이 보인다](../advanced/white-screen-release.md#basic) | 배포 · 캐시 · 관측성 · 사고 대응 | 기본 ([심화 경로](../advanced/white-screen-release.md#deep)) | 10~15분 |
| [공통 UI 패키지 패치 후 여러 앱이 깨진다](shared-package-release.md#basic) | 디자인 시스템 · 패키지 호환성 · 빌드 | 기본 ([심화 경로](shared-package-release.md#deep)) | 10~15분 |
| [테스트는 자주 실패하지만 결제 버그는 놓친다](flaky-checkout-tests.md#basic) | 테스트 전략 · 회귀 검증 · 멘토링 | 기본 ([심화 경로](flaky-checkout-tests.md#deep)) | 10~15분 |
| [새 기능과 레거시 개선을 함께 진행해야 한다](../../common/legacy-modernization.md#basic) | 리팩토링 · 위험 관리 · 도구 도입 | 기본 ([심화 경로](../../common/legacy-modernization.md#deep)) | 10~15분 |
| [AI가 만든 코드를 이해하지 못한 채 머지하려 한다](../../common/ai-generated-change-review.md#basic) | AI 검증 · 보안 · 학습 · 책임 | 기본 ([심화 경로](../../common/ai-generated-change-review.md#deep)) | 10~15분 |

첫 상황에서는 관찰 사실과 가정을 구분하는지, 두 번째에서는 선택의 한계와 실패 시 복구·검증을 설명하는지 확인하세요. 공통 질문도 별도 지식 시험처럼 추가하지 말고 실제 경험으로 이어갑니다.
