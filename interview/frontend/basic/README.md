# 프론트엔드 기본 상황 선택

[전체 진행 방법](../../README.md) · [평가 주제 대조표](../../coverage.md)

상황 1개를 골라 지원자의 답변에 맞는 분기 1~2개만 진행합니다. 기본은 10~15분, 심화는 15~20분이며 경력 연수 대신 관찰한 설명과 검증 근거로 평가합니다. 같은 상황의 기본·심화는 한 문서에서 조건을 달리합니다.

| 상황 제목 | 평가 역량 | 난이도 | 예상 시간 |
|---|---|---|---|
| [빠르게 검색하면 이전 결과가 마지막에 보인다](search-result-race.md#basic) | JavaScript 비동기 · 클로저 · Effect | 기본 ([심화 경로](search-result-race.md#deep)) | 10~15분 |
| [정렬 후 입력값이 다른 행으로 이동한다](editable-list-state.md#basic) | React 동일성 · 상태 소유권 · 폼 | 기본 ([심화 경로](editable-list-state.md#deep)) | 10~15분 |
| [모바일 결제 창이 잘리고 키보드로 닫을 수 없다](mobile-dialog-layout.md#basic) | CSS 레이아웃 · 접근성 · 협업 | 기본 ([심화 경로](mobile-dialog-layout.md#deep)) | 10~15분 |
| [검색 입력과 첫 화면 표시가 느리다](../advanced/input-rendering-lag.md#basic) | 이벤트 루프 · 렌더링 · 성능 측정 | 기본 ([심화 경로](../advanced/input-rendering-lag.md#deep)) | 10~15분 |
| [저장 성공 뒤 목록과 상세의 값이 다르다](../advanced/stale-product-cache.md#basic) | 서버 상태 · 캐시 계층 · 렌더링 모델 | 기본 ([심화 경로](../advanced/stale-product-cache.md#deep)) | 10~15분 |
| [배포 후 로그인과 주문 화면 통신이 실패한다](../advanced/login-and-contract-failure.md#basic) | 인증 · 브라우저 보안 · BFF · 계약 검증 | 기본 ([심화 경로](../advanced/login-and-contract-failure.md#deep)) | 10~15분 |
| [공통 UI 패키지 패치 후 여러 앱이 깨진다](../considerations/shared-package-release.md#basic) | 디자인 시스템 · 패키지 호환성 · 빌드 | 기본 ([심화 경로](../considerations/shared-package-release.md#deep)) | 10~15분 |
| [리뷰 의견 충돌로 배포가 지연된다](../../common/review-and-mentoring.md#basic) | 코드 리뷰 · Git · 멘토링 · 의사결정 | 기본 ([심화 경로](../../common/review-and-mentoring.md#deep)) | 10~15분 |

첫 상황에서는 관찰 사실과 가정을 구분하는지, 두 번째에서는 선택의 한계와 실패 시 복구·검증을 설명하는지 확인하세요. 공통 질문도 별도 지식 시험처럼 추가하지 말고 실제 경험으로 이어갑니다.
